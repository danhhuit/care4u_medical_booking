# Care4U Medical Booking

Ứng dụng đăng ký khám chữa bệnh với trung tâm y tế, cho phép:

- Đăng ký / đăng nhập
- Xem danh sách bác sĩ
- Chọn chuyên khoa
- Đặt lịch khám
- Xem lịch hẹn
- Nhận thông báo nhắc lịch

## Công nghệ sử dụng

- Flutter
- Dart
- GitHub

## Cấu trúc thư mục

- lib/app
- lib/core
- lib/features
- lib/shared

## Cách chạy dự án

```bash
flutter pub get
flutter run
```
